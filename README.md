## Обо мне

Я занимаюсь OSINT и веду Telegram-канал **solvnox project**.

Пишу про поиск и проверку информации, цифровой след, HUMINT, анонимность, Telegram, крипто-OSINT и инструменты для работы с открытыми источниками. В канале выходят статьи, разборы, подборки сервисов и новости моих проектов.

На GitHub выкладываю собственные инструменты. Здесь есть всё — от генератора поисковых запросов и каталога OSINT-ресурсов до анализа инфраструктуры, блокчейна и публичных Steam-профилей.
